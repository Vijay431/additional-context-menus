# Support

This article explains where to get help with Additional Context Menus.

## How to file issues and get help

This project uses [GitHub Issues](https://github.com/Vijay431/additional-context-menus/issues) to track bugs and feature requests. Before opening a new issue, please search existing issues to avoid duplicates.

- **Bug reports and feature requests**: Open an issue using the appropriate [issue template](https://github.com/Vijay431/additional-context-menus/issues/new/choose).
- **Questions and general discussion**: Use the [VS Code Marketplace Q&A](https://marketplace.visualstudio.com/items?itemName=VijayGangatharan.additional-context-menus&ssr=false#qna) or open a `documentation`/`configuration` issue.
- **Security vulnerabilities**: Do **not** open a public issue. Follow the [SECURITY.md](SECURITY.md) disclosure process instead.
- **Contributing code**: See [CONTRIBUTING.md](CONTRIBUTING.md) for local setup and contribution guidelines.

Additional Context Menus is maintained by a single maintainer on a best-effort basis — there is no SLA for response times, but issues are triaged regularly.
